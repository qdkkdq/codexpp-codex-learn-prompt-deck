提示词面板

gpt教你学习新知识提示词，悬浮在 Codex 窗口右侧。

- 拖动悬浮条的手柄可移动面板，位置保存在本机。
- 将鼠标放在等级名上滚动，循环切换六个等级。点击等级名查看适用场景与提示词。
- 用方向键也能切换，Esc 收起，点击「复制提示词」可复制全文。
- 展开后可恢复初始位置。


1. **学习曲线破坏者** — 完全没基础，想从零开始。
2. **真实错误模拟器** — 知道概念，却做不出题或用不起来。
3. **困惑破碎机** — 同一段内容读了很多遍，还是没明白。
4. **个人学习路径** — 目标很明确，却不知道怎么安排学习。
5. **隐藏漏洞检测器** — 感觉已经会了，想确认是不是真懂。
6. **强制费曼方法** — 刚学完，想把新知识真正变成自己的。
